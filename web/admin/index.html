🔌 Control por API & Terminal

Puedes subir y bajar o consultar este módulo independientemente mediante peticiones HTTP:

POST http://localhost:3006/api/admin/stop

Detiene el servidor de administración de manera segura.

curl -X POST http://localhost:3006/api/admin/stop
GET http://localhost:3006/api/admin/status

Consulta métricas, estado de la app principal y estadísticas.

curl http://localhost:3006/api/admin/status
PUT http://localhost:3006/api/admin/config

Actualiza mensajes fijos mediante JSON payload.

🚀 Comandos de Ejecución Independiente

Ejecuta la app y el módulo de administración en procesos separados:

Iniciar App Principal (Puerto 3005): 
go run .\cmd\app
Iniciar Módulo Admin (Puerto 3006): 
go run .\cmd\admin
